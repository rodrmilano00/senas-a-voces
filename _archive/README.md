# _archive — Proyectos obsoletos

Esta carpeta contiene proyectos de prueba y experimentos que ya no están en uso.
No se deben usar en producción. Se conservan como referencia histórica.

## Contenido

- **`imu_test/`** — Prueba del IMU BMI160 en ESP32 clásico (PlatformIO).
  Código de referencia para entender la comunicación I2C con el BMI160.
  El firmware de producción está en `../firmware/`.

- **`minimal_test/`** — Proyecto PlatformIO vacío, sin código fuente.
